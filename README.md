# Beyblade X DIY 轉速器 (DIY Beyblade X Tachometer by LCTAK)

本專案為 **Beyblade X (BX-09 款式)** 自製光電反射式轉速測試器（Tachometer）開源硬體項目，採用 **Seeed XIAO RP2040** 微控制器搭配 **QRE1113** 反射式光電感測器與 **0.91" OLED 螢幕**，支援即時出射轉速測量顯示。

> **注意**：本項目提供編譯後之 `.uf2` 韌體、3D 列印外殼模型（STL / 3MF）及硬體接線說明，不包含 Arduino 原始碼（`.ino`）。本產品僅支援即時轉速顯示，不支援連接官方 APP 功能。

  * `Pro_Version/`：Pro PCB 款外殼（`底殼.stl`、`上蓋.stl`、`L扣.stl`、`感應器壓片.stl`）
* `Docs/` — 接線圖與組裝教學資源
  * `DIY款接線圖.png`：手工焊接接線圖
  * `零件擺位.jpeg`：機殼內部零件安裝位置參考

## 🔧 製作與韌體燒錄步驟 (Assembly & Flashing Guide)

### 1. 硬體焊接與組裝
1. 列印對應版本（DIY 款或 Pro 款）之 3D 外殼零件，並備齊上述電子零件。
2. 焊線前請先在電線末端與焊點**預先上錫**。
3. 參照 `Docs/DIY款接線圖.png` 進行焊接（注意：**QRE1113 感應器凸起面向下擺放，電線焊接在背面**）。
4. 參照 `Docs/零件擺位.jpeg` 將模組固定於外殼內並鎖緊螺絲。

### 2. 刷入韌體 (Firmware Flashing)
1. **進入 Bootloader 模式**（以下兩種方式二選一）：
   * **方法 A**：按住 XIAO RP2040 板子上的 **`B` (Boot) 鍵**不放，然後插入 USB-C 傳輸線連接電腦。
   * **方法 B**：插入 USB-C 線後，按住板子上的 **`B` 鍵**不放，再按一下 **`R` (Reset) 鍵**，最後才放開 **`B` 鍵**。
2. 電腦會彈出一個名為 **`RPI-RP2`** 的 USB 儲存裝置（如同隨身碟）。
3. 將 `Firmware/` 資料夾內對應版本的韌體檔案拖入 `RPI-RP2` 磁碟中：
   * DIY 款請拖入：`Geo_BeyBladeX_V6.3.uf2`
   * Pro 款請拖入：`Geo_BeyBladeX_V6.3_Pro.uf2`
4. 複製完成後，`RPI-RP2` 儲存裝置會自動退出並重啟，OLED 螢幕顯示畫面即代表燒錄成功。

## ⚠️ 已知問題與使用須知

* **測速誤差與環境光影響**：QRE1113 光敏反射感應易受環境光線或角度影響，偶爾可能出現測不到轉速或數值偏離情況，數值僅供日常練發參考。
* **3D 列印公差**：外殼使用 FDM 或 SLA 光固化列印時，可能因機器公差需要微調打磨安裝位。
