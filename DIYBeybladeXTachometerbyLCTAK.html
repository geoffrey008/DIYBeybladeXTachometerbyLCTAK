更新韌體指南 (Firmware Update)

免裝驅動程式與編譯軟體，使用 RP2040 隨身碟拖放（UF2）方式更新。

01

拆卸外殼

使用螺絲批卸下機身背後的 6 顆螺絲，取下上蓋露出主控核心板。

圖1 · SEEED XIAO RP2040 核心板
02

連接電腦

使用具備數據傳輸功能的 Type-C 線連接電腦與轉速器主板。

USB Type-C 數據連線
03

進入Bootloader mode

1. 按住 BOOT 鍵不放
2. 輕按一下 RESET
3. 放開 BOOT 鍵

BOOT → RESET → RELEASE
04

識別磁碟

電腦會掛載跳出名為 RPI-RP2 的隨身碟磁區。

圖2 · 掛載 RPI-RP2 隨身碟
05

拖入韌體檔

將下載的 .uf2 檔案直接拖入隨身碟，主機將自動重啟完成更新。

自動退出磁碟並重啟
溫馨提示：

若電腦沒有偵測到 RPI-RP2 隨身碟，多數是因為使用的 Type-C 線材僅支援單純供電充電而無資料傳輸腳位，請換一條資料傳輸線並重新進入 Bootloader mode。

日常測速流程

開機即用 / 3 秒鎖定

開機 3 秒倒數後自動進入 Ready 待機狀態。發射後即時顯示最高轉速（Max RPM）約 3 秒，隨後自動回歸待機並保存紀錄。

歷史紀錄儲存

最多保存 500 筆

待機畫面右側常駐顯示最近 4 次測速數據；開機倒數時輕微轉動發射器可進入歷史數據瀏覽模式。

發射瞬間自動感應，左側大字顯示本次最高轉速，約 3 秒後自動保存並返回待機。

Auto Calibration 自動光敏校準教學

開機連續開關 3 次觸發

何時需要校準？當你第一次使用、更換發射器或發現測速出現異常時，請執行自動校準。

步驟 1 · 觸發校準

連續開關電源 3 次

螢幕跳出 Auto Calibration，並進行 5 秒倒數，請在這段時間內準備好發射陀螺。

步驟 2 · 8秒內用力拉發

等待畫面提示：Waiting Shoot...

畫面進入 8 秒倒數，請用力拉發陀螺一次。系統感應到旋轉後會自動進行光學對比採樣。

步驟 3 · 自動儲存門檻

顯示 Cal Done! 與 High / Low 數值

計算出最佳對比度門檻並自動寫入儲存，隨後返回 Ready 待機畫面，校準即告完成！

開機快捷操作一覽

開關 3 次

自動光敏校準 (Auto Cal)

自適應當前發射器，8 秒內發射陀螺即可完成最佳調整。

開關 5 次

重設原廠設定 (Reset)

5 秒內快速連續開關 5 次，螢幕顯示 CLEARED!，恢復初始光敏門檻並清除所有歷史紀錄。

開機轉動陀螺

瀏覽歷史數據 (History)

在開機倒數 3 秒內讓轉速計感測到轉動，即可進入紀錄瀏覽頁，右側固定顯示最高轉速（Top RPM）。

PRO SPECIFICATIONS

Pro 款操作手冊

三向按鍵操作定義

[ LEFT ] 左鍵 / 上

選單往上移動、數值遞減（-）、自訂名稱字元切換、歷史紀錄向前翻閱。

[ ENTER ] 中心確認鍵

• 短按：確認選取／進入下一層／儲存。
• 待機長按 2 秒：進入系統設定選單。
• 選單長按 1 秒：返回上一層選單或退出。

[ RIGHT ] 右鍵 / 下

選單往下移動、數值遞增（+）、自訂名稱字元切換、歷史紀錄向後翻閱。

Classic Mode (經典大字)

預設模式

左邊大字顯示測速結果，右邊直列顯示最近 4 次發射紀錄，最右側固定顯示 4 階電池圖示（低於 25% 時閃爍提示）。

Curve Mode (動態衰減曲線)

即時曲線

發射瞬間還原發射轉速動態，全螢幕繪製轉速衰減斜率圖，可於 Display Mode 選單中切換。

完整系統選單結構

待機長按 Enter 2 秒開啟
1. History (歷史紀錄)

翻查歷史發射數據；右側常駐顯示玩家的最高轉速 (Top) 與平均轉速 (Avg)。

2. User Select (玩家管理)

支援最多 10 位獨立玩家；可切換帳號、重新命名 (最多 15 字)、新增玩家與清除紀錄。

3. Display Mode (顯示模式)

自由切換 Classic Mode（經典數值排版）或 Curve Mode（轉速衰減曲線）。

4. Information (系統資訊)

檢視目前韌體版本，或直接掃描螢幕上顯示的 Telegram 交流群組點陣 QR Code。

5. Advanced (進階調校)
Bat Display
開啟/關閉電池 OSD 與低電量警示。
Sensor Threshold
手動微調光敏高低門檻或執行自動校準。
Launch Setting
調整最低轉速門檻 (預設 3500) 與結果鎖定秒數。
RGB LED
設定常亮、呼吸、彩虹、爆閃 4 種氣氛燈效。
